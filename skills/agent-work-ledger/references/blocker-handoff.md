# Blocker or handoff

Use when work cannot continue normally or must pass to another executor. Verify blockers with the `AGENTS.md` recovery budget.

For a blocker, record on the canonical execution surface: blocker, unblock condition, validation impact, remaining useful work, and exact next action. Continue independent useful work when appropriate; otherwise stop.

For a handoff, make that surface sufficient to resume without prior chat: completed/remaining work, blockers or constraints, validation state, material decisions, and exact next action.

Use comments only when notification or durable history is needed beyond current state.

## Done when

The unblock condition is explicit, or another executor can resume safely from durable state.
