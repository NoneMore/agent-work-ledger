# Prepare for Ready for Review

Use this path when a Draft PR should be normalized and validated for review.

1. Confirm exactly one tracking mode. For Issue-backed work, ensure every closing-linked Issue's acceptance criteria are satisfied or incomplete items are explicit; for standalone work, confirm the scope still fits that mode.
2. Read check summaries and unresolved actionable review feedback, then apply the recovery budget from `AGENTS.md` only far enough to account for intended scope, validation, and any review blockers.
3. Normalize the PR replacement snapshot: accurate `Current State`, validation actually performed, and only material limitations or incomplete items.
4. Apply the repository's authoritative readiness policy. Move Draft to Ready only with explicit user intent or clear repository delegation.

Never claim validation that was not performed.

## Done when

The PR satisfies readiness policy and its tracking/current state/validation match evidence. Without transition authority, leave it correctly prepared in Draft with the next action explicit.
